어드민 사용 매뉴얼

무진물산 랜딩페이지(mujin.im) 콘텐츠를 수정하고 배포하는 방법을 안내합니다.

목차
  1. 저장 및 배포 흐름
  2. 메타 / SEO 카드
  3. 콘텐츠 카드 (기업소개 ~ 푸터)
  4. 연락처 카드
  5. 스크립트 관리 카드
  6. SEO 파일 카드
  7. 배포 이력 관리
  8. 어드민 비밀번호 변경
1

저장 및 배포 흐름

어드민에서 내용을 수정한 뒤에는 반드시 저장 버튼을 눌러야 랜딩페이지에 반영됩니다. 미리보기에 적용했더라도 저장을 누르지 않으면 실제 사이트에는 아무런 변화가 없습니다.

⚠️
저장 후 약 2~3분이 지나야 mujin.im에 반영됩니다 저장 버튼을 누르면 GitHub에 커밋이 생성되고, Cloudflare Pages가 자동으로 새 배포를 시작합니다. 배포가 완료되기까지 2~3분 소요되며, 그 전에 방문하면 이전 내용이 표시됩니다.
1
원하는 카드의 항목을 수정합니다.
2
전체 미리보기 적용 버튼을 눌러 우측 미리보기 화면에서 결과를 확인합니다. (사이트에는 아직 반영되지 않음)
3
이상이 없으면 상단의 저장 버튼을 누릅니다.
4
2~3분 후 mujin.im을 새로고침하여 변경 내용을 확인합니다.

배포가 완료됐는지 확인하려면 상단의 배포 진행상황 버튼을 클릭하세요. Cloudflare Pages 대시보드가 열리며, 가장 최근 배포의 상태가 Success로 바뀌면 반영이 완료된 것입니다.

배포 진행상황 화면 — 상태가 Success로 표시되면 반영 완료
2

메타 / SEO 카드

검색엔진(구글, 네이버)과 SNS 공유 시 노출되는 정보를 관리합니다. 사이트 방문자 수와 첫인상에 직접 영향을 미치므로, 회사명·주요 사업이 바뀌거나 대표 이미지를 교체할 때 반드시 함께 수정해 주세요.

페이지 타이틀
브라우저 탭과 검색결과에 표시되는 제목. 20~60자 권장.
메타 설명
검색결과 제목 아래 나오는 설명 문구. 70~160자 권장.
키워드
검색엔진에 전달하는 키워드. 쉼표로 구분.
OG 이미지
카카오톡·SNS 링크 공유 시 자동으로 표시되는 대표 이미지.
💡
언제 수정해야 하나요?
  • 회사명, 주요 사업, 연락처 등 핵심 정보가 변경될 때
  • 검색 노출을 개선하고 싶을 때 (타이틀·설명·키워드 최적화)
  • SNS/카카오톡에서 링크 공유 시 나오는 이미지나 제목을 바꾸고 싶을 때
  • 대표 이미지(OG 이미지)를 시즌에 맞게 교체할 때
3

콘텐츠 카드 (기업소개 ~ 푸터)

랜딩페이지의 각 섹션 내용을 수정하는 카드들입니다. 수정한 항목은 미리보기에서 먼저 확인한 뒤 저장하세요.

기업소개
회사 소개 문구, 인용구, 인증·협회 배지 목록
컨설팅
컨설팅 섹션 배경 이미지, 타이틀, 설명
온라인몰
자체몰·네이버몰 버튼 표시 여부, URL, 라벨, 버튼 색상
관계회사
관계회사 카드 목록 (순서 드래그 변경 가능)
푸터
회사명, 대표자, 사업자번호, 주소
4

연락처 카드

전화번호, 이메일, 네이버 블로그 URL을 관리합니다. 연락처는 랜딩페이지 내 여러 곳에 공통으로 사용되므로, 이 카드 하나만 수정하면 페이지 전체에 일괄 반영됩니다.

전화번호
페이지 내 전화 연결 링크에 공통 적용
이메일
페이지 내 이메일 링크에 공통 적용
네이버 블로그 URL
블로그 버튼 클릭 시 이동할 주소
📌
연락처가 바뀌었을 때 이 카드만 수정하면 됩니다. 페이지 내 여러 위치에 흩어진 연락처를 따로 찾아 수정할 필요가 없습니다.
5

스크립트 관리 카드

랜딩페이지의 <head> 또는 <body> 영역에 삽입되는 외부 스크립트를 직접 편집할 수 있습니다.

⚠️
잘못된 스크립트는 페이지를 망가뜨릴 수 있습니다 HTML/JavaScript에 익숙하지 않다면 이 카드는 수정하지 않는 것을 권장합니다. 반드시 미리보기로 확인한 뒤 저장하세요.
💡
언제 수정해야 하나요?
  • Google Analytics, 네이버 애널리틱스 등 분석 도구 추적 코드를 추가·변경할 때
  • Google Search Console, 네이버 서치어드바이저의 사이트 소유권 확인 코드를 삽입할 때
  • 카카오톡 채널 상담 버튼, 채팅 위젯 등 외부 서비스 플러그인을 연동할 때
  • 광고 픽셀(Meta, Kakao) 코드를 삽입하거나 업데이트할 때
6

SEO 파일 카드

robots.txt와 sitemap.xml 두 파일을 직접 편집합니다. 검색엔진이 사이트를 올바르게 수집(크롤링)하고 색인하는 데 필요한 파일들입니다.

robots.txt
검색엔진 크롤러의 접근 허용 범위를 지정. 구글·네이버 서치콘솔 등록 시 필요.
sitemap.xml
사이트 페이지 목록을 검색엔진에 알림. 제출 시 색인 속도 향상.
💡
언제 수정해야 하나요?
  • 구글서치콘솔 또는 네이버 서치어드바이저에 사이트를 처음 등록할 때
  • 페이지 구조가 바뀌어 sitemap.xml의 URL 목록을 업데이트해야 할 때
  • 특정 경로를 검색엔진에서 숨기거나 다시 허용할 때
⚠️
SEO 파일 카드의 저장 버튼은 다른 카드들과 별도로 동작합니다. SEO 파일을 수정한 뒤에는 해당 카드 안의 저장 버튼을 따로 눌러야 하며, 마찬가지로 2~3분 후 반영됩니다.
7

배포 이력 관리

상단 배포 이력 버튼을 클릭하면 최근 5개의 저장 이력이 표시됩니다. 잘못 수정한 내용이 있을 경우 이전 버전으로 되돌릴 수 있습니다.

1
상단 오른쪽의 배포 이력 버튼을 클릭합니다.
2
오른쪽에서 슬라이드되어 나오는 패널에서 되돌리고 싶은 시점을 선택합니다.
3
해당 항목의 이 버전으로 복원 버튼을 누르면 그 시점의 내용으로 즉시 저장됩니다.
4
복원 후에도 2~3분 후에 mujin.im에 반영됩니다.
📋
배포 이력은 최근 5개까지만 표시됩니다. 그 이전 내용은 GitHub 저장소의 커밋 히스토리에서 확인할 수 있습니다.
8

어드민 비밀번호 변경

어드민 로그인 비밀번호는 Cloudflare Pages 대시보드에서 변경합니다. 로그인 유지 기간은 7일이며, 7일이 지나면 다시 로그인해야 합니다.

📍
버튼 위치 어드민 왼쪽 패널 맨 아래에 🔐 어드민 비밀번호 변경 ↗ 버튼이 있습니다. 클릭하면 아래와 같은 Cloudflare 설정 페이지로 바로 이동합니다.
1
아래 링크를 클릭해 Cloudflare Pages 어드민 설정 페이지를 엽니다.
Cloudflare Pages — mujin-admin 설정 ↗
2
Environment variables 섹션에서 ADMIN_PASSWORD 항목을 찾습니다.
3
항목 오른쪽의 Rotate 버튼을 클릭하면 새 비밀번호로 변경할 수 있습니다.
4
변경 후 Save를 눌러 저장합니다. 이후 로그인 페이지에서 새 비밀번호로 로그인하세요.
Cloudflare Pages 어드민 설정 — Environment variables 섹션
Rotate 버튼을 눌러 새 비밀번호를 생성합니다
🔐
로그인 유지 기간: 7일 로그인 후 7일이 지나면 자동으로 로그아웃되며, 다시 비밀번호를 입력해야 합니다. 보안을 위해 정기적으로 비밀번호를 변경하는 것을 권장합니다.
